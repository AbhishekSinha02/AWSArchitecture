> **"The best architects don't memorize services — they understand the story behind each decision."**
>
> Think of this guide as a mentor sitting across from you, walking you through every topic
> you'll face — from your first cloud job interview to staff-level system design rounds.

## How to Use This Guide

```
1. Start at your level — don't skip beginner if you're rusty on fundamentals
2. Read the story first — each answer is written like a real explanation, not bullet spam
3. Speak it out loud — practice saying answers, not reading them
4. Connect the dots — each topic references others; follow the links
```

## Interview Mindset

```
Before answering:  "Let me make sure I understand — are you asking about X or Y?"
During answer:     Start with the 1-line answer. Then explain why. Then give a real example.
When stuck:        "I'd approach that by first clarifying the requirement — is this latency-sensitive?"
Ending:            "Does that answer what you were looking for, or shall I go deeper on X?"
```
